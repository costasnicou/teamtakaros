# Homepage audio playlist

1. Open **Site Content → Hero** in the WordPress dashboard (CMB2 must be active).
2. Under **Homepage audio playlist**, choose **Select or upload audio**. MP3 is a good choice for browser compatibility.
3. Use **Add track** for more tracks and the group arrows to set playback order.
4. Click **Save content** before leaving the page.

The player appears below the red services strip only when valid audio attachments are selected. The strip stays directly below the homepage cover. Visitors press Play to start; WordPress automatically advances through the tracks and repeats the playlist after the last track. There is no autoplay on page load. Visitors can pause, seek and change volume. Track titles and the track list are hidden. Playback does not persist across page navigation.

Remove tracks here and save to remove them from the playlist without deleting the audio files. Remove all tracks to hide the section. Deleted or trashed attachments and non-audio selections are ignored. The existing Site Content account can manage this playlist using its current permissions.
